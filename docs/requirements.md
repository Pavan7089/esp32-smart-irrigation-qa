# Requirements

| ID | Requirement |
|---|---|
| R1 | Keep soil moisture between 35 % and 55 % |
| R2 | Publish readings every 10 seconds |
| R3 | Keep controlling the pump when Wi-Fi is unavailable |
| R4 | Stop the pump after 30 seconds of continuous running |
| R5 | The pump must be OFF at power-up |
| R6 | No passwords or keys stored in the repository |
